# Block Game

A small single-page Tetris-style falling block game built with JavaScript, React, and Material UI.

## Run locally

```bash
npm install
npm run dev
```

Open the Vite dev server URL shown in the terminal.

## Build

```bash
npm run build
```

## Controls

- Left Arrow: move left
- Right Arrow: move right
- Down Arrow: soft drop
- Up Arrow: rotate
- Spacebar: hard drop
